vdf @VERSION@

vdf (visual disk free) shows the output of df -h with a horizontal colour-gradient bar for each physical disk and each mounted volume.

This installer adds:

  • /usr/local/bin/vdf, a universal binary for Apple silicon and Intel
  • /usr/local/share/man/man1/vdf.1, the manual page

Source code and documentation: github.com/jggonz/vdf
